# Nuit Lumière — план реализации

## Подход

Продолжить магазин в существующем тёмном, золотом, минималистичном направлении, сохраняя редакционную композицию главной страницы. Основа — управляемый Webdev starter: React/wouter для страниц и взаимодействий, Express/tRPC для публичного и административного API, Drizzle/MySQL для каталога и заказов. Клиент получает только публичные поля каталога; merchant secrets остаются на сервере.

Корзина хранит slug и количество в `localStorage`, показывает мини-корзину в шапке и пересчитывает суммы по загруженным товарам. На сервере перед записью заказа повторно проверяются актуальные активные товары, цены и количества; складской учёт не заявляется. Checkout собирает имя, email, телефон, адрес/отделение и способ доставки. Доступны только Nova Poshta и Ukrposhta внутри Украины; суммы — в UAH.

`/admin` использует настоящую Manus OAuth-сессию и `adminProcedure`, который проверяет серверную роль `admin`. Права не имитируются на клиенте. Владелец назначает администраторский email через защищённый `NUIT_ADMIN_EMAIL`; раздел позволяет просматривать заказы, менять их статус и добавлять/редактировать продукты. При редактировании slug передаётся исходный slug, чтобы обновить существующую запись без дубликата.

LiqPay Checkout формируется сервером и подписывается тестовыми merchant keys, которые обязаны начинаться с `sandbox_`; живые ключи отвергаются, чтобы сайт не инициировал реальные списания. Ответ подтверждается только после проверки подписи callback, публичного merchant key, order ID, суммы и UAH. При отсутствии test keys checkout помечается как не настроенный, заказ остаётся pending и интерфейс не утверждает, что оплата состоялась. Секреты добавляются только через защищённый ввод.

## Структура проекта

- `client/src/pages/` — Home, Collection, About, Cart, Checkout, результат оплаты, Contact, Privacy и Admin.
- `client/src/components/Storefront.tsx` — общая навигация, mini-cart, карточки и цена; `MusicControl.tsx` сохраняет музыкальный control исходника.
- `client/src/contexts/CartContext.tsx` — корзина, количество, удаление и синхронизация с `localStorage`.
- `client/public/media/` и `client/public/perfumes/` — предоставленное hero-фото и локальные изображения продуктов.
- `client/public/manus-routes.json` — манифест реальных страниц SPA.
- `server/routers.ts` — каталог, серверная валидация checkout, защищённые действия Admin.
- `server/liqpay.ts`, `server/_core/index.ts` — test checkout, callback и проверка платёжного заказа.
- `server/db.ts`, `drizzle/schema.ts`, `drizzle/` — операции с продуктами/заказами и additive MySQL migrations.
- `shared/catalog.ts` — типы и демонстрационный seed-каталог.
- `.env.example`, `README.md` — названия настроек и инструкции без секретных значений.

## Дизайн

**Дизайн-движение:** вечерний editorial luxury для нишевой парфюмерии: меньше декора, больше тёмного пространства и выразительных стеклянных флаконов.

**Основные принципы:** сохранить знакомую главную композицию; держать интерфейс почти чёрным и чистым; использовать золото как редкий акцент; делать коммерческие действия понятными и короткими.

**Цветовая логика:** угольно-чёрный и глубокий сине-чёрный задают ночной фон; приглушённое шампанское-золото связывает бренд и CTA; тёплые отражения предоставленного флакона становятся единственным ярким визуальным событием.

**Композиция:** асимметричный hero с крупным заголовком и фотографией справа; далее — редакционный заголовок коллекции и сдержанная адаптивная витрина. Шапка остаётся тонкой; checkout и admin используют те же тёмные поверхности без смены визуального режима.

**Фирменные детали:** тонкие золотые разделители; мягкая виньетка/ореол вокруг стекла; serif-wordmark и спокойные компактные подписи.

**Взаимодействия и анимация:** добавление в корзину сразу обновляет количество и subtotal; состояния видны в тексте и aria-label; hover и переходы — короткие fade/translate без отвлекающих эффектов; поля и кнопки доступны с клавиатуры.

**Типографическая система:** Cormorant Garamond для крупных редакционных заголовков с Georgia как запасным serif; компактный системный sans для навигации, форм и метаданных.

**Суть бренда:** выразительные ароматы для людей, которым близка тихая вечерняя элегантность; характер — ночной, утончённый, собранный.

**Голос бренда:** краткий, спокойный и образный. Примеры: “Composed for the quiet beauty of evening.” “A considered selection of memorable compositions.”

**Знак и собственный цвет:** типографический wordmark Nuit Lumière с деликатным световым акцентом; фирменный оттенок — приглушённое шампанское-золото.

## Ограничения

Для полноценной проверки платежей нужны test merchant keys владельца LiqPay и адрес администратора; ввод не должен попадать в ZIP или Git. Официальные тестовые ключи LiqPay начинаются с `sandbox_`. Доставка реализована как выбор Nova Poshta/Ukrposhta и ввод адреса/отделения, без live API-тарифов и поиска отделений: carrier credentials/контракты не предоставлены. Managed MySQL общий для разработки и публикации; тестовые действия не должны создавать фиктивные customer orders.

Vercel guide отражает исходный стек, а не обещает совместимость только установкой env: frontend собирается в `dist/public`, backend — в Express entrypoint `dist/index.js`; этот репозиторий пока не содержит serverless adapter. Для запуска backend нужны MySQL DSN и Manus OAuth values, а LiqPay/admin values остаются опциональными для соответствующих функций. Все примеры переменных являются безопасными шаблонами, не действующими credential values.
